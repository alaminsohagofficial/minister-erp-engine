# ⚡ Minister ERP & Dual-Dealer Secure Financial Ledger Engine (Single-Service Edition)

একটি প্রোডাকশন-রেডি ফ্লাস্ক (Python/Flask) বেজড অল-ইন-ওয়ান আর্কিটেকচার, যা মিনিস্টার হাই-টেক পার্ক (`DEAL002905`) এবং সলসাবিলা ইলেকট্রনিক্স পার্ক (`MDEL000215`) এর ফিনান্সিয়াল লেজার বাইপাস, রিয়েল-টাইম পেমেন্ট সিনক্রোনাইজেশন এবং ফান্ড রিকনসিলিয়েশন পরিচালনা করে। এছাড়া জেমিনী এআই (Gemini API) দিয়ে তাৎক্ষণিক ডায়নামিক বাংলা নোটিফিকেশন এবং উইজপ্রিন্ট (WeasyPrint) ইঞ্জিনের সাহায্যে অফিসিয়াল পিডিএফ ডকুমেন্ট প্রস্তুত করে।

---

## 🌟 মূল ফিচারসমূহ (Key Features)

- **ডুয়েল-ডিলার বাইপাস সিস্টেম:** `DEAL002905` এবং `MDEL000215` এর লেজার ব্যালেন্স ও SAP অ্যালোকেশন (BDT 35,189,545.00) নিরাপদে রিকনসিল করার সুবিধা।
- **ACID ডাটাবেজ ট্রানজেকশন:** SQLite ও ফ্লাস্কের মাধ্যমে ট্রানজেকশন রোলব্যাক সুরক্ষা প্রদান।
- **জেমিনী এআই (Gemini AI) নোটিফিকেশন:** লেনদেন ও বকেয়া ব্যালেন্সের ওপর ভিত্তি করে রিয়েল-টাইমে পেশাদার বাংলা এসএমএস জেনারেট করে।
- **উইজপ্রিন্ট (WeasyPrint) পিডিএফ ইঞ্জিন:** স্বয়ংক্রিয়ভাবে অফিসিয়াল লেজার রিপোর্ট পিডিএফ জেনারেট করে।
- **কার্ড-ফ্রি রেন্ডার ডিপ্লয়মেন্ট:** কোনো এক্সট্রা সার্ভিস বা বিলিং কার্ডের ঝামেলা ছাড়াই সিঙ্গেল পাইথন ওয়েব সার্ভার হিসেবে রান করার উপযোগী।

## 🛠️ টেক স্ট্যাক (Tech Stack)

- **Backend / Web Server:** Python 3.9+, Flask, SQLite3
- **PDF & UI Engine:** WeasyPrint, Embedded HTML/CSS Dashboard
- **AI Integration:** Google GenAI SDK (Gemini 2.5 Flash)
- **Deployment:** Render (Python Web Service)
