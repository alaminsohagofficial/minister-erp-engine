# ⚡ Minister ERP & Dual-Dealer Secure Financial Ledger Engine

একটি প্রোডাকশন-রেডি ডুয়েল-স্ট্যাক (Node.js + Python) আর্কিটেকচার, যা মিনিস্টার হাই-টেক পার্ক (`DEAL002905`) এবং সলসাবিলা ইলেকট্রনিক্স পার্ক (`MDEL000215`) এর ফিনান্সিয়াল লেজার বাইপাস, রিয়েল-টাইম পেমেন্ট সিনক্রোনাইজেশন এবং ফান্ড রিকনসিলিয়েশন পরিচালনা করে। এছাড়া জেমিনী এআই (Gemini API) দিয়ে তাৎক্ষণিক ডায়নামিক বাংলা নোটিফিকেশন এবং উইজপ্রিন্ট (WeasyPrint) ইঞ্জিনের সাহায্যে অফিসিয়াল পিডিএফ ডকুমেন্ট প্রস্তুত করে।

---

## 🌟 মূল ফিচারসমূহ (Key Features)

- **ডুয়েল-ডিলার বাইপাস সিস্টেম:** `DEAL002905` এবং `MDEL000215` এর মাধ্যমে অ্যাকাউন্ট লক বা সীমাবদ্ধতা কাটিয়ে লেজার ব্যালেন্স ও SAP অ্যালোকেশন (BDT 35,189,545.00) নিরাপদে রিকনসাইল করার সুবিধা।
- **ACID ডাটাবেজ ট্রানজেকশন:** পেমেন্ট বা ওভাররাইড রিকোয়েস্ট আসার সাথে সাথে ব্যাংক ব্যালেন্স বৃদ্ধি, স্টক হ্রাস এবং কাস্টমার লেজার আপডেট নিশ্চিত করে রোলব্যাক সুরক্ষা প্রদান করে।
- **জেমিনী এআই (Gemini AI) নোটিফিকেশন:** লেনদেন ও বকেয়া ব্যালেন্সের ওপর ভিত্তি করে রিয়েল-টাইমে পেশাদার বাংলা এসএমএস জেনারেট করে।
- **উইজপ্রিন্ট (WeasyPrint) পিডিএফ ইঞ্জিন:** স্বয়ংক্রিয়ভাবে অফিসিয়াল ডকুমেন্ট ও ইনভয়েস জেনারেট করে।
- **সিকিউর কনফিগারেশন:** ক্রিপ্টোগ্রাফিক সিগনেচার এবং `.env` ফাইলের মাধ্যমে API Key ও সিক্রেট ডেটা সুরক্ষিত রাখা।
